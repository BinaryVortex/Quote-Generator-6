# Quote Generator

A simple, responsive Quote Generator built with HTML, CSS, and JavaScript.

![App screenshot](./Screenshot%202024-09-03%20200250.png)

## Demo
A lightweight app that shows a random inspirational quote each time the button is pressed.

## Features
- Generates a random quote on button click
- Clean, minimal responsive UI
- Easy to read and extend — add more quotes in script.js

## Technologies
- HTML
- CSS
- JavaScript

## Getting started
1. Clone the repository:

   git clone https://github.com/BinaryVortex/Quote-Generator-6.git

2. Open `index.html` in your browser (no build tools required).

## Files
- `index.html` — app markup
- `style.css` — styles and layout
- `script.js` — quote logic and UI behavior
- `Screenshot 2024-09-03 200250.png` — app screenshot

## How it works
The JavaScript file contains an array of quotes and a function that picks a random quote and updates the page when you click the button.
